# Бот с ручным добавлением точек

Распакуйте в новую отдельную папку. Скопируйте из прежнего .env только BOT_TOKEN и ALLOWED_USER_IDS. Программа сама загружает .env рядом с bot.py. Прокси, Google Sheets и Playwright не используются. База manual-points.sqlite3 создаётся рядом с bot.py. Прежняя база не изменяется и не импортируется.

В PowerShell в новой папке:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe bot.py
```

Если старая виртуальная среда доступна, можно запускать её Python с полным путём, передав новый bot.py. Старый бот сначала остановите Ctrl+C; для одного токена запускайте один процесс.

Кнопки постоянные: Добавить, Список, Проверка, Статистика.

- Добавить: название организации → город → адрес → просмотр → Сохранить/Отмена. На шагах организации и города предлагаются кнопки с уникальными значениями из базы; можно также ввести новое значение текстом. Подсказки города включают все города базы. Каждое добавление создаёт одну точку. /cancel отменяет незавершённое добавление. Любая основная кнопка тоже отменяет текущий ввод. Ссылка не запрашивается.
- Список: организация → город → одно сообщение с названием организации, городом, количеством точек и нумерованным списком адресов. Очень длинные списки разделяются из-за лимита Telegram. Ссылки не показываются.
- Проверка: ищет название организации в локальной базе без учёта регистра и лишних пробелов.
- Статистика: общее количество точек, уникальных организаций и городов; количество точек по каждой организации и каждому городу.

Одинаковые названия объединяются без учёта регистра и лишних пробелов. Географические сокращения не угадываются: пишите города последовательно. Совпадение организации, города и адреса считается дублем. Существующая база совместима: записи сохраняются, прежние ссылки не отображаются. Редактирование и удаление пока не предусмотрены. Данные общие для всех разрешённых ID. Доступ только в личной переписке.

Сохранённые записи остаются после перезапуска. Незавершённый ввод теряется; старые кнопки выбора после перезапуска не действуют. Делайте резервную копию базы при остановленном боте.

Проверка:

```powershell
.\.venv\Scripts\python.exe -m unittest -v test_manual
```
